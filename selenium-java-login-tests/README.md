# Selenium + JUnit 5: UI-тесты

Автотесты для страницы логина https://the-internet.herokuapp.com/login

## Стек
Java, Selenium WebDriver, JUnit 5, WebDriverManager, Maven

## Что проверяется
- успешный вход с корректными данными
- сообщение об ошибке при неверном пароле

## Запуск
Команда: mvn test
Требуется установленный Chrome.
